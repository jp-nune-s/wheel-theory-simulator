Visualizador educativo

Roda projetiva

Um único campo calcula expressões comuns e mostra famílias com incógnitas, como em uma calculadora gráfica.

Resultado para os valores atuais —

Os controles x e c são deslizantes, como os parâmetros de uma calculadora gráfica.

Espelhar a visualização

Os espelhos alteram a orientação do desenho, não o valor algébrico calculado.

Digite uma expressão e pressione Enter ou Calcular. Use x e c para visualizar uma família de resultados.

Raios e valores

x ↦ x + c

Reta projetiva real
valores reais ∞: eixo absorvente ⊥ = 0/0: colapso ao centro

A circunferência representa a reta projetiva: 0 fica no polo sul e +∞/−∞ no polo norte. ⊥ é um elemento adicional; o centro iluminado indica visualmente o colapso, não um ponto da circunferência. Os raios rotulados mostram valores de referência e amostras da expressão.
