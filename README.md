# Wheel Theory Simulator

Simulador educativo em HTML, CSS e JavaScript, sem processo de compilação ou dependências.

## Executar localmente

Abra `index.html` no navegador ou sirva a pasta com:

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`.

## Arquivos

- `index.html`: interface e operações rápidas.
- `styles.css`: layout e aparência.
- `script.js`: parser, aritmética exata de racionais e desenho do círculo projetivo.

O protótipo representa `∞` no polo norte da reta projetiva e `0` no polo sul. `⊥ = 0/0` é desenhado separadamente, pois não é um ponto da reta projetiva. A implementação é uma versão didática reduzida da roda dos racionais; consulte a documentação matemática antes de usar como referência formal.
